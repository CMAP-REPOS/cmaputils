About
=====
``cmaputils`` is a package meant to make it easier to work with Census
data and to create crosswalks to make that data more useful.
``cmaputils`` contains (or will soon hopefully) a number of functions
which provide clean interfaces for getting CTPP data, ACS data, Census
data, and more (soon to come).

This project is still in early stages of development. As such, any and
all functions/methods/classes may be subject to breaking changes. Please
send any and all feedback to `arumph@cmap.illinois.gov <mailto:arumph@cmap.illinois.gov>`_
