# CMAPUTILS

## About:
`cmaputils` is a package meant to make it easier to work with 
Census data and to create crosswalks to make that data more useful.
`cmaputils` contains (or will soon hopefully) a number of functions
which provide clean interfaces for getting CTPP data, ACS data,
Census data, and more (soon to come).

This project is still in early stages of development. As such, any and all
functions/methods/classes may be subject to breaking changes.
Please send any and all feedback to arumph@cmap.illinois.gov!

## Installation:
At the moment, the best way to install cmaputils is by cloning
this repository, and then installing it with pip/uv.

You can clone the repository by running the following command
in your preferred location:
```shell
$ git clone https://github.com/CMAP-REPOS/cmaputils.git
```
You can then add the package to your Python environment by
going into the new `cmaputils` directory and installing it
with pip/uv as follows:
```shell
$ cd cmaputils
$ pip install .
```

or if you're using uv:
```shell
$ cd cmaputils
$ uv pip install .
```

The plan is to eventually make the package available from pip/uv/conda
so that users can use either
```shell
$ uv pip install cmaputils
```
or
```shell
$ conda install cmaputils
```
